Project Title: Snake Water Gun – Advanced Python GUI Application

Description: This project is a feature-rich, graphical adaptation of the classic decision-making game "Snake Water Gun" (a variant of Rock Paper Scissors), developed using Python and the Tkinter library. Moving beyond simple command-line interactions, this application offers a robust Graphical User Interface (GUI) with a modern "Dark Mode" aesthetic, ensuring an engaging user experience.

Key Technical Features: The core logic utilizes the random module for unpredictability and complex conditional statements to determine round outcomes. A standout feature is the implementation of File Handling (I/O), which automatically saves and retrieves the user's "High Score" from a local file (highscore.txt), demonstrating data persistence. The application also includes a dynamic Match History Log to track recent moves and a "Streak Counter" to gamify the experience.

Educational Value: This project serves as a practical demonstration of Event-Driven Programming, Algorithm Design, and Data Persistence. It bridges the gap between raw logic and visual software development, showcasing the ability to build interactive, end-to-end software solutions.

Key Concepts Highlighted:
GUI Development: tkinter (Widgets, Layout Management).

File Handling: Reading/Writing high scores to text files.

Logic & Algorithms: Conditional structures and random number generation.

Data Structures: Dictionaries for mapping choices and Lists for history logging.

Snake Water Gun - GUI Game
This is a simple desktop game I created using Python. It’s a variation of the classic Rock-Paper-Scissors game, but with a graphical interface (GUI) instead of just running in the terminal.

About the Game
I built this using the tkinter library. The game lets you play against the computer. It tracks your score, your winning streak, and even saves your high score so it’s there when you come back later.

Rules
The logic is simple:

Snake drinks Water (Snake wins).

Water damages Gun (Water wins).

Gun shoots Snake (Gun wins).

If both choose the same, it's a Draw.

Features
Graphical Interface: Dark mode theme with colored buttons.

High Score System: The game creates a highscore.txt file to save your best score permanently.

Match History: A log on the screen shows the last few moves so you can track the game.

Visual Effects: The background flashes Green when you win and Red when you lose.

Streak Counter: Counts how many times you win in a row.

Requirements:
Python installed on your system.

No external libraries are needed (Tkinter comes with Python).

How to Run:
Download the PROJJECT.py file.

Open your terminal or command prompt in the folder.

Run the following command:

python PROJJECT.py
